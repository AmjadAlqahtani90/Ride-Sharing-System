# Ride Sharing System

A simple Ride Sharing System implemented using **C++ and Smalltalk** to demonstrate Object-Oriented Programming (OOP) concepts.

## Features

- Standard and Premium rides
- Riders and drivers
- Ride assignment
- Fare calculation
- Ride history
- Demonstrates inheritance, polymorphism, and encapsulation

## C++ Version

### How to Run

```bash
cd Ride-Sharing-System
./run.sh
```

If permission is denied:

```bash
chmod +x run.sh
./run.sh
```

You can also compile manually:

```bash
g++ -std=c++17 *.cpp -o rideshare
./rideshare
```

## Smalltalk Version

Open the Smalltalk environment and load the Smalltalk source files from the project.

Then run the main program or test file included in the Smalltalk implementation.

```bash
cd Ride-Sharing-System/pharo/RideSharing
./run.sh
```
